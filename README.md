# Projects

## Database Generator
I wanted to easily create and share databases of interesting math facts and data.
So I created this little app that can generate a simple website from a database and
can be used to edit it as well.
- [repo for the app](https://github.com/obousquet/math_database)
- [current databases](https://obousquet.github.io/Mathematical-Structures/)

## Concept Classes and Combinatorial Parameters
As a first application of the database generator, I have created two databases related
to the combinatorial structures that arise in theoretical Machine Learning: concept classes
and their complexity parameters (e.g. VC dimension,
Teaching dimension, Littlestone dimension...).
For the concept classes themselves, the focus is on partial cubes (i.e. concept classes that
embed isometrically into the hypercube) as these have particularly nice and rich properties.
- [Combinatorial Parameters Database](https://obousquet.github.io/Combinatorial-Parameters)
- [Partial Cubes](https://obousquet.github.io/Partial-Cubes)
