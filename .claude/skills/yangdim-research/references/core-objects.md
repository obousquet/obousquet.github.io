# Core YangDim objects and notation

Load this packet for shared notation only. Route-specific hypotheses, current theorem status, and proof debts belong in the narrower topic skills, `prescribed_dual_bridge_realization.tex`, or the active ledger.

## The objects (and how they connect)

- **Concept class** `H ⊆ 2^[n]`, a set of binary vectors / subsets of `[n]`.
- **Trace** `(S,f)`: a partial assignment `f:S→{0,1}`, `S⊆[n]`, realized by some `h∈H`. The **trace
  class** `T(H)` = all realizable partial assignments.
- **Yang complex** `Δ_H`: pure `(n-1)`-dim simplicial complex on vertex set `X×{0,1}` (the `2n`
  literals `v_{x,b}`); facets are `F_h = {(x,h(x)) : x∈[n]}`. **Faces of Δ_H = traces T(H)** (the
  identification `T(H)=faces(Δ_H)` is used everywhere; the empty trace is the empty face).
- **Yang ideal** `I_{Δ_H} ⊆ k[v]` = Stanley–Reisner ideal of Δ_H (generators: contradictions
  `v_{x,0}v_{x,1}` and extentures). **Dual** `I*_{Δ_H}` generated by `m_h = ∏_x v_{x,1-h(x)}`.
- **Extenture.**  A minimal missing trace.  For the recurring non-ampleness warning, use
  `terminology.md`.
- **Vanishing ideal** `I^0_H ⊆ k[x]` of H as a point set.
- **Cube lattice** `L(H)` = lcm-lattice of `I*_{Δ_H}`: cubes `C(S)` = smallest subcube containing
  `S⊆H`. Do NOT confuse with `T(H)` (traces are arbitrary partial assignments; cubes are
  agreement-complete).
- **hd(H) := pd(I*_{Δ_H}) = reg(I_{Δ_H})** (Eagon–Reiner). Hochster/lcm give it combinatorially:
  `hd = 1 + max{ j : H̃_j(Δ_H[W]) ≠ 0, some W⊆ literals }` (this is what the code computes).
