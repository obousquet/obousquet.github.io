# Local-CM and Buchsbaum overview

This is an overview for local-CM profile questions. Load one focused packet.

## Stable status

- `CM_t` is a local Yang-complex hierarchy: every realized partial assignment of size at least `t` has ample version class.
- The local-CM radius `t^*(H)` satisfies `t^*(H)=0` iff `H` is ample.
- The broad numerical gap bound `hd(H)-VC(H)<=t^*(H)` is proved, with sharper trace-link profiles available.
- Buchsbaum base-gap counterexamples are now excluded by `thm:buchsbaum_hd_equals_vc`; historical Buchsbaum obstruction packets are useful mainly for proof-route audits.
- The live refinement is not whether Buchsbaum gives `hd=VC`; it is how to translate higher trace-link kernels into concept-class/cubical bridge data.
