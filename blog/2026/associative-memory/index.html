The same algorithm, three axes

In 1960, Widrow and Hoff introduced the delta rule [1]: given a target $y$ and input $x$, update a weight matrix by the error-corrective rule

$$W \leftarrow W + \eta\,(y - Wx)\,x^\top$$

This is gradient descent on the squared loss $\frac{1}{2}\|y - Wx\|^2$, applied once per training example. Over six decades it became a cornerstone of adaptive filtering and online learning, known as the LMS or Widrow–Hoff rule.

In 2024, Yang et al. introduced DeltaNet [2], a sequence model that updates a memory matrix once per token:

$$S_t \leftarrow S_{t-1} + (v_t - S_{t-1} k_t)\, k_t^\top$$

DeltaNet knowingly borrows the delta rule — the paper cites Widrow and Hoff. But what has not been fully appreciated is how exact the correspondence is. This is literally the same algorithm with a change of variable names: keys $k_t$ play the role of inputs $x$, values $v_t$ play the role of targets $y$, and the memory $S_t$ plays the role of the weight matrix $W$ (with normalized keys and learning rate $\eta = 1$). The algebra is identical; only the axis of computation changes — from training examples to tokens.

Same algorithm, different axis. This turns out to be the tip of an iceberg. The same pattern — one operation appearing independently along different axes — repeats across a surprising range of techniques.

This post is about that structure. Large language models perform iterative state updates along three axes of computation — sequence, depth, and data — that were studied largely in isolation as separate topics: sequence modeling, deep network design, and optimization. Strikingly similar techniques were developed independently along each axis, without the full extent of the shared structure being recognized. We argue that a single operation, viewed as a state update, an attention mechanism, or a gradient step on a cost function, unifies them all.

Three axes of computation

The common pattern is a state update: retain part of the old state and add new information. In its simplest form, the state is a vector:

$$s_t = a_t \cdot s_{t-1} + b_t$$

where $a_t$ is a retention factor (scalar, diagonal, or matrix) and $b_t$ is the new input. This covers RNNs, SSMs, residual networks, and momentum buffers.

When the state stores associations between keys and values, it becomes a matrix $S \in \mathbb{R}^{d_v \times d_k}$, and each write is a rank-one outer product:

$$S_t = A_t \circ S_{t-1} + v_t\, k_t^\top$$

where $A_t$ controls element-wise forgetting, $k_t$ is a key, and $v_t$ is a value. Retrieval for a query $q$ is simply $y = S_t\, q$. This covers linear attention (sequence axis) and weight matrices updated by gradient descent (data axis). A vector state is the special case $d_k = 1$: there is no key, just a value being accumulated. Recent work on matrix-valued RNNs [19] confirms that upgrading from vector to matrix hidden states improves capacity, consistent with this view.

Both forms appear across many domains. The key insight is that the index $t$ is not always the same thing — it runs along three different axes of computation:

  • Sequence axis ($t$ = token): the KV cache accumulates information about past tokens. This is working memory.
  • Depth axis ($\ell$ = layer): the residual stream is refined by each layer. This is processing memory.
  • Data axis ($n$ = example): the weight matrix is updated by each gradient step. This is long-term memory.

These three axes were not always distinct. In early RNNs, the sequence and data axes were conflated: each element in the input sequence was itself a training example (online learning from a stream of patterns). The two axes only became fully decoupled with batched training over sequences of tokens, where a single training sample contains an entire sequence. This gradual separation helps explain why similar techniques were developed independently along each axis.

The associative memory lens

The state update is really a memory operation: information is written into a state and later retrieved using a query. This perspective reveals a fundamental tradeoff that governs all three axes. Feed-forward network (FFN) layers are themselves associative memories [3]: the weight matrices store key-value associations learned during training, and a forward pass through the FFN is a retrieval operation. Training — updating $W$ via gradient descent — is precisely the state update applied along the data axis.

Two extremes: attention vs. state update

Attention (store everything). Keep all key-value pairs explicitly: the memory is the list $(k_1, v_1), \ldots, (k_T, v_T)$. Retrieval computes similarities with all stored items: $y = \sum_j w(q, k_j)\, v_j$. This is lossless — no information is discarded — but costs $O(Td)$ memory and computation per query, growing linearly with the number of stored items.

State update (compress). Maintain a fixed-size matrix $S \in \mathbb{R}^{d_v \times d_k}$ that accumulates information via rank-one writes: $S_t = A_t \circ S_{t-1} + v_t k_t^\top$. Retrieval is $y = S_t\, q$, costing $O(d^2)$ regardless of how many items have been stored. But compression is lossy: patterns interfere with each other.

These correspond to the attention view and recurrent view of sequence processing. A chunk (or mini-batch) interpolates between them: within a chunk, use attention; between chunks, compress into state. Mini-batch SGD is the data-axis analogue of chunked attention.

The delta rule: error-corrective writing

Between the two extremes lies a spectrum of write strategies. The simplest write is additive (Hebbian): $S_t = S_{t-1} + v_t k_t^\top$, which ignores what is already stored. The delta rule introduced above improves on this by writing only the prediction error $(v_t - S_{t-1} k_t)$, avoiding redundant storage. More generally, we can arrange write strategies in a hierarchy of increasing sophistication:

MethodSequence axisDepth axisData axis
AdditiveLinear attentionResidual connectionHebbian learning
Error-correctiveDeltaNet / Gated DeltaNet [15]Hyper-connectionsWidrow–Hoff / SGD
NormalizedNormalized DeltaNetPre-Norm (RMSNorm)NLMS

The table above is formulated in the general asymmetric case (keys $\neq$ values), which is the most relevant for LLMs. In the symmetric case ($k = v$), the memory must satisfy $S = S^\top$, and the delta rule must be adapted to preserve this constraint. This is precisely what the Storkey learning rule [11] does: it adds a second correction term $-v_t(S^\top v_t)^\top$ that accounts for reverse-direction crosstalk, ensuring the update remains symmetric. In the asymmetric case, this second term is unnecessary (we never read from $S^\top$), so the Storkey rule reduces to the standard delta rule.

This means the classical associative memory community independently discovered the same progression of write strategies — from Hebbian to error-corrective (Storkey) to exponential-kernel (modern Hopfield) — before it appeared on the sequence axis (linear attention → DeltaNet → softmax attention). The capacity jumps at each step are the same: $O(d/\log d) \to O(d) \to e^{O(d)}$.

The table is also asymmetric across axes: the data axis has richer methods (Muon, natural gradient) that have no current sequence-axis counterparts. Bernstein and Newhouse [23] show that Adam, Shampoo, and Muon are all steepest descent under different norms, reinforcing the view that these represent different points in the hierarchy. LUCID [24] applies preconditioning to the sequence-axis readout, achieving gains analogous to how natural gradient preconditions data-axis updates. This points to unexplored architectures: what would a "Muon-style" sequence model look like?

Capacity and the SNR

How many items can a fixed-size memory reliably store? For a linear outer-product memory with $N$ random patterns of dimension $d$, the retrieval signal-to-noise ratio is:

$$\mathrm{SNR}_{\text{linear}} = \frac{d}{N}$$

The memory saturates (SNR = 1) at $N_{\max} \sim d$ patterns. For softmax attention (modern Hopfield networks [6]), the exponential kernel amplifies the gap between matched and mismatched patterns, yielding exponential capacity:

$$\mathrm{SNR}_{\text{softmax}} \sim \frac{e^{O(d)}}{N} \quad\Longrightarrow\quad N_{\max} \sim e^{O(d)}$$

The kernel choice determines the capacity-computation tradeoff:

MethodKernelState sizeCapacityCompute/query
Full softmax attn$\exp(q^\top k)$$O(Nd)$$e^{O(d)}$$O(Nd)$
Linear (compressed)$q^\top k$$O(d^2)$$O(d)$$O(d^2)$
Polynomial$(q^\top k)^p$$O(d^{2p})$$O(d^p)$$O(d^{2p})$
Random features$\approx\exp(q^\top k)$$O(Dd)$$O(D)$$O(Dd)$

An important subtlety: keeping all $N$ key-value pairs does not by itself guarantee exact retrieval. The capacity is determined by the kernel, not the storage strategy. With a linear kernel, full attention computes $\sum_j (k_j^\top q)\, v_j = Sq$ where $S = \sum_j v_j k_j^\top$ — the same output as the compressed form. Storing all pairs is wasteful because the linear readout cannot exploit them individually.

Softmax is different: its exponential kernel gives capacity $e^{O(d)} \gg N$ for typical sequence lengths, so it can exploit the stored pairs. But it cannot be compressed into finite state without approximation, so it inherently requires $O(Nd)$ storage. Chunked attention interpolates: within each chunk, use full attention; between chunks, compress into $O(d^2)$ state.

This tradeoff is universal: it governs the sequence axis (linear vs. exponential kernel) and the data axis (MSE vs. cross-entropy loss). As we will see, the cost function determines the kernel, and hence the capacity.

Multi-head structure: block-diagonal memory

Multi-head attention splits the $d$-dimensional space into $H$ independent heads of dimension $d_h = d/H$. In the state view, this means the memory matrix is block-diagonal: $S = \mathrm{diag}(S^{(1)}, \ldots, S^{(H)})$, where each $S^{(h)} \in \mathbb{R}^{d_v \times d_h}$ is an independent memory with capacity $O(d_h)$. Different heads can specialize in different types of patterns.

This structure transfers to both other axes. On the depth axis, hyper-connections [9] maintain $n$ parallel residual streams — exactly $n$ independent depth-axis memories. The residual matrix transformer [7] goes further: its matrix-valued residual state can be viewed as multiple independent rank-one "heads" accumulated across layers. Standard residual networks correspond to $H = 1$: a single stream with no block structure.

On the data axis, a block-diagonal weight matrix means each block is an "expert" that sees only a slice of the feature space. This is a dense mixture of experts (MoE) without routing, where the partitioning is along the feature dimension. Standard MoE with routing is different: each expert has full-rank weights, but a learned gating function directs different tokens to different experts — the data-axis analogue of input-dependent head selection on the sequence axis. Grouped-query attention (GQA), where multiple query heads share fewer KV heads, corresponds to fewer experts with multiple ways of reading from each.

Block-diagonal memoryMulti-head attentionHyper-conn. streamsDense MoE (feature-part.)
Input-dep. routingHead selectionAdaptive depthSparse MoE with routing

Three equivalent views

Along each axis, the same computation can be expressed in three equivalent ways: as a recurrent state update, as an attention mechanism, or as a gradient step on a cost function.

State Space Duality

The observation that a recurrent computation can also be expressed as a parallel matrix multiply (with a causal mask) is not new — it appears in DeltaNet [2] and in earlier work on linear attention. What Dao and Gu [4] added with the State Space Duality (SSD) framework is the identification of the algebraic structure that makes this work: the input-output map of a linear recurrence is a semiseparable matrix, and the recurrent and attention views are two different factorizations of this matrix. This structure is what enables efficient chunked algorithms and makes precise which recurrences admit an exact attention dual.

The cost-update duality

There is a deeper question: why does the state update have this particular form? In most cases, it arises as a gradient step on a cost function [14]. The form of the cost determines the update rule, the kernel, and the capacity. The same cost form applied to different axes gives corresponding systems:

Cost formSequence axisData axisCapacity
Linear (alignment)Linear attentionHebbian$O(1)$/step
Quadratic (MSE)DeltaNetWidrow–Hoff / SGD$O(d)$
Log-sum-expSoftmax attentionCross-entropy$e^{O(d)}$

The quadratic cost on the sequence axis gives DeltaNet's delta rule; the same cost on the data axis gives Widrow–Hoff. The log-sum-exp cost on the sequence axis gives softmax attention (via the modern Hopfield energy [6]); on the data axis, the same cost is cross-entropy with softmax outputs.

Cross-entropy training is the data-axis analogue of softmax attention. Both arise from the log-sum-exp cost form, and both achieve exponential capacity — the ability to separate exponentially many patterns. This suggests that natural gradient on cross-entropy is, in a precise sense, the data-axis optimizer that matches softmax attention's retrieval performance.

The chain from cost to capacity

The cost function determines a complete cascade:

$$\mathcal{L} \;\xrightarrow{\;\nabla\;}\; \text{update rule} \;\xrightarrow{\;\nabla^2\;}\; \text{local metric} \;\xrightarrow{\;\text{Mercer}\;}\; \text{kernel} \;\xrightarrow{\;\text{capacity}\;}\; \text{SNR}$$

The gradient gives the update rule. The Hessian gives the local metric (preconditioning by the Hessian inverse = natural gradient). The metric induces a kernel: for instance, the Fisher information matrix of cross-entropy defines a kernel where nearby points (in probability space) are those the model finds hard to distinguish, concentrating updates on difficult examples. The kernel determines the memory capacity and retrieval SNR. Choosing the cost fixes all of these simultaneously.

Positional encoding = forget gate

One of the most striking consequences of this framework is a complete unification of positional encodings and recurrent forget gates, established by Afzal [5]. This is directly validated by FoX [16], which replaces positional encoding in softmax attention with a data-dependent forget gate, and by PaTH [17], which implements PE via accumulated Householder reflections.

In the recurrent view, the contribution of input at position $j$ to the state at position $t$ is attenuated by the cumulative product of transition matrices: $P_{j \to t} = \prod_{s=j+1}^{t} A_s$. This product defines an asymmetric distance between positions: $d(j,t) = -\log \|P_{j \to t}\|$. The algebraic structure (monoid) of the transition matrices determines both the recurrent decay and the equivalent positional encoding:

Transition monoidRecurrencePositional encoding
$\{I\}$ (trivial)Linear attentionNoPE
$\mathbb{R}_{>0}$ (scalars)RetNetALiBi
Diagonal matricesMamba2 / GLAFoX [16]
$\mathrm{SO}(2)$ (rotations)Complex-valued gates (Mamba-3 [18])RoPE
Householder reflectionsDeltaNetPaTH [17]

This extends to the data axis. SGD with weight decay has a forget gate $(1 - \lambda\eta_n)I$. The learning rate schedule $\eta(s)$ controls how much influence past gradients retain at the current step — exactly the role of positional encoding on the sequence axis. In this sense, the learning rate schedule is the positional encoding of the data axis:

LR scheduleData-axis geometrySequence-axis analogue
Constant $\eta_0$Uniform exponential decayALiBi / RetNet
Adam (per-parameter)Diagonal adaptive decayFoX / Mamba2
Cosine annealingLinear + sinusoidalSinusoidal PE
Curriculum learningInput-dependent gatingMamba / FoX

Concretely: with $\lambda = 0.1$ and $\eta_0 = 10^{-3}$, gradients have a half-life of about 7,000 steps. Adam's bias correction $\hat{m}_n = m_n / (1 - \beta_1^n)$ is an explicitly position-dependent rescaling — a schedule-free warmup built into the optimizer.

Depth as inner loop

The three axes are not symmetric. The sequence and data axes are outer loops that accumulate persistent state. The depth axis is always an inner loop, nested inside one of them:

ModeInner axisOuter axisPersistent state
InferenceDepth ($\ell$)Sequence ($t$)KV cache $S_t^{(\ell)}$
TrainingDepth ($\ell$)Data ($n$)Weights $W^{(\ell)}$

At inference, each token triggers a complete forward pass through all layers. The residual stream $x^{(\ell)}$ is ephemeral — it exists only during this traversal and is discarded afterward. The persistent state (KV cache) lives on the sequence axis. At training, each example similarly triggers a full forward-and-backward depth traversal, and the persistent state (weights) lives on the data axis.

This means depth "mixes" with each outer axis. The KV cache update involves quantities produced by the depth computation:

$$S_t^{(\ell)} = S_{t-1}^{(\ell)} + \underbrace{v_t^{(\ell)}}_{\text{computed by layers } 1\ldots\ell}\;(k_t^{(\ell)})^\top$$

And the weight gradient is a depth-data product:

$$\Delta W^{(\ell)} = \sum_n \underbrace{\delta_n^{(\ell)}}_{\text{backprop through depth}}\;(x_n^{(\ell-1)})^\top$$

The depth axis is the shared computational substrate through which both outer axes operate. This explains why the residual stream is ephemeral (it belongs to an inner loop), why there's no persistent depth-axis memory (only the outer axes carry persistent state), and why backpropagation is fundamentally a depth×data operation rather than a pure data-axis operation.

Recent work has enriched the depth axis with richer state-update structure. As discussed in the multi-head section above, hyper-connections [9] generalize residual connections with learnable mixing matrices (a non-trivial transition operator), and residual matrix transformers [7] replace the residual stream with a matrix-valued state, making the depth axis structurally identical to the sequence axis. Attention Residuals [20] go further, replacing fixed residual accumulation with softmax attention over the depth axis, explicitly motivated by depth-time duality, and achieving ${\sim}1.25\times$ compute-equivalent improvement.

Cross-axis transfer

Unification is most valuable when it yields predictions. Here are several concrete transfers.

Critical batch size = memory capacity

The retrieval SNR in a linear memory with $N$ patterns of dimension $d$ is $d/N$. On the data axis, the gradient SNR for a mini-batch of size $B$ is:

$$\mathrm{SNR}_{\text{grad}}(B) = \frac{B\,\|G\|^2}{\mathrm{tr}(\Sigma)}$$

where $G$ is the true gradient and $\Sigma$ is the per-example gradient covariance. The critical batch size [8] — where SNR = 1 — is the retrieval capacity of the data-axis memory:

$$B_{\text{crit}} = \frac{\mathrm{tr}(\Sigma)}{\|G\|^2}$$

The optimal batch size $B^* \sim B_{\text{crit}}$ corresponds to the optimal chunk size $C^* \sim d$ in chunked attention: both are the point where switching from "parallel/attention" mode to "recurrent/state" mode becomes worthwhile.

Cross-entropy as exponential-capacity optimizer

The cost hierarchy predicts that natural gradient on cross-entropy should achieve exponentially better gradient SNR compared to SGD on MSE, just as softmax achieves exponentially better retrieval SNR compared to linear attention. The mechanism: cross-entropy's Fisher information concentrates on hard examples (where the model is uncertain), ignoring easy ones. This "attention to difficulty" is the data-axis analogue of softmax's exponential pattern separation.

Normalization as manifold projection

The same cross-axis pattern extends to normalization: softmax projects attention weights onto the probability simplex, RMSNorm projects the residual stream onto the sphere, and Muon's polar decomposition projects weights onto the Stiefel manifold. Each is a metric projection onto a compact manifold that keeps the memory well-conditioned. Normalization breaks the semiseparable structure underlying the SSD duality, which is why it is applied between recurrent steps (between layers, at read time) rather than inside the recurrence.

New design principles

The framework suggests several unexplored combinations:

  • The rich positional encoding literature (RoPE, ALiBi, FoX) should directly inspire learning rate schedule design.
  • An "RLS-Net" that maintains the inverse key-correlation matrix as additional recurrent state could achieve optimal single-pass learning.
  • Spectral normalization methods (Muon-style) applied to sequence-axis memory updates could improve capacity.
  • Finding optimizers with rotational or reflective decay structure would complete the analogy with RoPE and PaTH on the sequence axis.

Where the analogy breaks

Intellectual honesty requires acknowledging the limits of unification.

Exact vs. structural analogy. The SSD duality on the sequence axis is an exact algebraic identity: the recurrent and attention views compute literally the same thing. The depth-axis duality (proved by Zhang [10]) is also exact but has not been cast in the semiseparable matrix framework. The data-axis duality (online SGD vs. batch gradient) is a structural analogy — the "batch attention" over the entire dataset is typically infeasible.

Single-pass vs. iterated. On the sequence axis, the model makes a single pass over tokens. On the data axis, multiple epochs allow convergence to solutions (like the pseudoinverse) that a single pass can only approximate. Data-axis methods can be more powerful than their sequence-axis analogues.

Depth has no independent cost. On the sequence and data axes, the state update minimizes a cost along that axis. The depth axis has no independent local cost — the forward pass is inference, not optimization. The cost that shapes it is the global training loss, propagated backward through backprop. This is why depth mixes with the data axis during training.

Nonlinearity complicates transfer. The linear framework transfers cleanly. But practical systems use nonlinearities (softmax, activation functions, adaptive optimizers) that break the semiseparable structure. Hu et al. [22] make this precise: extending SSD from scalar to diagonal SSMs works, but the duality fails for softmax attention due to rank explosion. M²RNN [19] and COFFEE [25] similarly introduce nonlinearities (matrix-valued and state-dependent updates) that break semiseparable structure but improve expressiveness. The cost-centric view helps (different costs yield different nonlinearities), and feature map lifting — rewriting a nonlinear kernel as linear attention in a higher-dimensional space — can restore the linear framework approximately. But these are approximations rather than exact dualities.

Open questions

  • The rotation monoid on the data axis. RoPE uses rotational transitions for periodic positional structure. What optimizer has a rotational forget gate? Perhaps something related to cyclical learning rates?
  • Quantifying exponential capacity. Can we compute $B_{\text{crit}}$ for cross-entropy vs. MSE on a simple model and verify the predicted exponential gap?
  • Depth-axis positional encoding. Standard residual connections use $A = I$ (no decay). Hyper-connections use learned mixing. What geometry does this induce across layers?
  • The normalization–manifold conjecture. Softmax projects onto the simplex, RMSNorm onto the sphere, polar decomposition onto the Stiefel manifold. Is every normalization in deep learning a metric projection onto a compact manifold, with the manifold determined by the algebraic structure of the memory?
  • An RLS-Net. DeltaNet approximates the pseudoinverse in a single pass. RLS achieves it exactly by also maintaining the inverse key-correlation matrix. Can this be implemented efficiently as a recurrent architecture?

Two concurrent works pursue related unifications: Behrouz et al. [12] view sequence architectures as associative memories with four design axes (memory architecture, attentional bias, retention gate, learning algorithm), though focused on the sequence axis only; Wang et al. [13] frame associative recall as a two-step regression problem. Our contributions beyond these are the three-axis view (including depth and data), the cost-update duality, the PE = forget gate unification, and cross-axis transfer predictions.

The unified view doesn't just explain existing systems — it maps out a design space. Many combinations of (axis, monoid, cost, normalization) have not been explored. The framework suggests that ideas proven effective on one axis should have natural counterparts on the other axes waiting to be discovered.
