What is shared across three axes?

A model incorporates new information when a token arrives, when a layer transforms its representation, and when a training example changes its parameters. Calling these the sequence, depth, and data axes gives a useful comparison. The state, its persistence, and its read operation differ across the axes.

AxisStateNew information
SequenceRecurrent memory or stored keys and valuesToken representations
DepthResidual representation, usually temporaryLayer output
DataParameters and optimizer statisticsLoss gradients

Three concrete read/write examples

Data axis. For one dense application with $W\in\mathbb R^{d_{\rm out}\times d_{\rm in}}$ and input $z\in\mathbb R^{d_{\rm in}}$, let $f_{\rm rest}$ be the rest of the forward computation and $\ell(\cdot,v)$ the scalar loss against target $v$. Read, compute, retain/transform, and write are

$$\begin{aligned}a&=\underbrace{Wz}_{\text{read}},\qquad\mathcal L=\underbrace{\ell(f_{\rm rest}(a),v)}_{\text{compute forward/loss}},\\\delta&=\underbrace{\nabla_a\mathcal L}_{\text{compute backward}},\qquad G=\underbrace{\delta z^\top}_{\text{compute gradient}},\\W^+&=\underbrace{W}_{\text{retain/transform}}+\underbrace{(-\eta G)}_{\text{write}},\quad\eta>0.\end{aligned}$$

A Transformer reuses the same matrix at many token positions, so backpropagation adds the contribution from each use:

$$a_t=Wz_t,\qquad\delta_t=\frac{\partial\mathcal L}{\partial a_t},\qquad\nabla_W\mathcal L=\sum_{t=1}^T\delta_tz_t^\top.$$

Each $\delta_t$ comes from the full sequence loss and includes downstream effects. With mini-batches, gradient contributions from the examples are accumulated (and averaged if required by the loss) before the update is applied. SGD writes the negative summed gradient; adaptive optimizers modify that rule.

Sequence axis. At the sequence-memory boundary, the read produces a contextual output and the write retains information for future tokens. Preparing the query/write inputs and transforming the retrieved output are surrounding computations using weight and residual memory.

For a pre-normalized attention head, prepare $z_t=\operatorname{Norm}(h_t)\in\mathbb R^d$ and $(q_t,k_t,v_t)=(W_Qz_t,W_Kz_t,W_Vz_t)$, with $q_t,k_t\in\mathbb R^{d_k}$ and $v_t\in\mathbb R^{d_v}$. Then

$$\begin{aligned}y_t&=\underbrace{\sum_{j=1}^t\alpha_{tj}v_j}_{\text{read}},\qquad c_t=\underbrace{W_Oy_t}_{\text{compute residual contribution}},\\\mathcal C_t&=\underbrace{\mathcal C_{t-1}}_{\text{retain/transform}}\mathbin{\Vert}\underbrace{[(k_t,v_t)]}_{\text{write}}.\end{aligned}$$ $$\alpha_{tj}=\frac{\exp(q_t^\top k_j/\sqrt{d_k})}{\sum_{i=1}^t\exp(q_t^\top k_i/\sqrt{d_k})}.$$

Here $W_O\in\mathbb R^{d\times d_v}$, $\Vert$ is list concatenation, and $\mathcal C_0=[]$. Scoring keys, softmax, and value aggregation together constitute the memory read. The current pair participates before being committed, equivalently to appending first and then attending. The cache stores the new key/value pair, not $y_t$ or $c_t$; older records remain. The projected output $c_t$ is a residual contribution. Attention computes substantially within its read, but no extra transformation of $y_t$ is needed to perform the cache write.

For a simple linear SSM, let $s_t\in\mathbb R^m$, input $z_t\in\mathbb R^d$, $A\in\mathbb R^{m\times m}$, $B\in\mathbb R^{m\times d}$, and $C\in\mathbb R^{d_v\times m}$. The same input yields an output and updated memory:

$$\begin{aligned}y_t&=\underbrace{C(As_{t-1}+Bz_t)}_{\text{read}},\\s_t&=\underbrace{As_{t-1}}_{\text{retain/transform}}+\underbrace{Bz_t}_{\text{write}}.\end{aligned}$$

The read includes the pending current-input contribution, just as attention includes its pending current pair. An implementation can compute $s_t$ once and read $Cs_t$. Its write uses the old state and input, rather than $y_t$; a separate post-read computation is optional. At the memory level, both fit

$$y_t=R(M_{t-1},u_t),\qquad M_t=U(M_{t-1},u_t),$$

where $M$ is the cache or state and $u_t$ contains the prepared inputs. This states two output dependencies, not two independent execution routines. Attention keeps a growing list; this SSM compresses history into $m$ entries. Unrolling gives

$$y_t=CA^t s_0+\sum_{j=1}^t CA^{t-j}Bz_j.$$

For $A=I_m$, its update has the same retain-and-add form as residual propagation, across tokens instead of sublayers. Linear attention supplies an intermediate example with outer-product writes and a compressed read.

Depth axis. For a pre-normalized Transformer sublayer, $\operatorname{Norm}:\mathbb R^d\to\mathbb R^d$ and $F_\ell:\mathbb R^d\to\mathbb R^d$ give

$$u=\underbrace{\operatorname{Norm}(h^{(\ell-1)})}_{\text{read}},\qquad c_\ell=\underbrace{F_\ell(u)}_{\text{compute}},\qquad h^{(\ell)}=\underbrace{h^{(\ell-1)}}_{\text{retain/transform}}+\underbrace{c_\ell}_{\text{write}}.$$

The next sublayer reads the updated stream. In plain SGD, cache appending, and residual addition, retention is the identity; the SSM applies $A$. The presentation is read, compute, retain/transform, then write. Computation may include further memory reads; within the sequence-memory module the retrieval can encompass the output computation, and a separate post-read computation may be absent. Weight reads form attention inputs, attention computes a contextual output, and its projection is written into the residual stream.

The clearest exact connection is the delta rule. Given a key $k$, a target value $v$, and a matrix $S$, gradient descent on $\tfrac12\|Sk-v\|^2$ gives

$$S^+=S+\eta(v-Sk)k^\top.$$

This is the classical Widrow–Hoff update and the write rule used in DeltaNet, with matching step sizes and key-normalization conventions. Applying it to tokens rather than training examples changes the role of the state, not this formula.

The broader account is a synthesis of fast-weight memories, linear attention, structured state space duality, and optimization-based sequence memories. In particular, it builds on Miras and test-time regression. It does not assert a new universal capacity theorem.

Three memories: storage, retrieval, and computation

The three axes give three kinds of memory: long-term information in weights, short-term context in sequence states or attention caches, and intermediate inference results in the residual stream. Their distinction is persistence and use; all three can be tensors. Training writes weights, while the forward pass reads those weights and reads or writes the other memories.

Memory / axisReadComputeRetain/transform and write
Weights / dataForward evaluation: $Wz$, embedding lookup, tensor contractionCompose forward reads into predictions; during training compute the loss, backward derivatives, and update directionKeep or decay weights and apply the computed optimizer step
Sequence / tokensRetrieve context by attention or a state readoutPrepare projections or input contributions and optionally transform the retrieved outputKeep records and append new pairs, or transform the old state and add a contribution
Residual / depthRead the current stream, often after normalizationApply the attention or feedforward operator using weights and contextCarry or mix the old stream and add the computed sublayer output

Retrieval here means an input-dependent read of retained information; it need not recover one named fact exactly. Computation forms queries, combines reads, transforms results, and produces further writes. These roles overlap: $Wz$ is both a learned transformation and a read of weight memory. A delta write itself reads the old sequence state through $Sk$. A write input need not depend on the retrieved output: a basic attention cache stores the newly prepared pair. At the memory-module boundary, a separate post-read computation can simply be absent. The architecture fixes whether a read happens before or after a write.

A block makes the interaction explicit

Take an unnormalized single-head linear-attention block, omitting biases and normalization. For residual $h\in\mathbb R^d$, weight matrices $Q,K\in\mathbb R^{d_k\times d}$, $V\in\mathbb R^{d_v\times d}$, $O\in\mathbb R^{d\times d_v}$, $W_1\in\mathbb R^{p\times d}$, and $W_2\in\mathbb R^{d\times p}$, one possible forward block is

$$q=Qh,\quad k=Kh,\quad v=Vh,\quad S^+=U_{\rm seq}(S;k,v),\quad a=S^+q,$$ $$\bar h=h+Oa,\qquad h^+=\bar h+W_2\sigma(W_1\bar h).$$

Here $\sigma$ acts coordinatewise, $S\in\mathbb R^{d_v\times d_k}$, and $U_{\rm seq}$ can be an additive or delta write. The projections read weight and residual memory to form a query and write inputs. The state read retrieves sequence context, which $O$ transforms into a residual write. The feedforward sublayer reads the modified residual through its weights, transforms it, and writes another contribution. Ordinary softmax attention uses a cache read instead.

Training closes the loop

During ordinary inference the weights remain fixed; layer-specific sequence memories persist across tokens, and each token starts a new residual traversal. During training the forward pass uses the current weights, the loss evaluates its output, backward differentiation computes gradients from weights and saved or recomputed activations, and the optimizer writes the next weights. Optimizer moments influence that write and are usually absent from inference. Test-time adaptation can add weight writes inside inference.

Thus weight memory determines how sequence writes, queries, and residual computations are formed, while their outputs determine later training writes. Persistence and update frequency are separate properties. The framing complements Miras, test-time regression, and Nested Learning; it does not require every residual update to optimize an objective or every parameter to store a separately recoverable fact.

Write, retain, and read

All vectors below are columns. Keys and queries lie in $\mathbb R^{d_k}$, values in $\mathbb R^{d_v}$, and the memory $S$ has shape $d_v\times d_k$. Set $K=[k_1,\ldots,k_N]$ and $V=[v_1,\ldots,v_N]$.

Additive memory stores $S_N=\sum_i v_i k_i^\top=VK^\top$. Its read is

$$S_Nq=\sum_i v_i(k_i^\top q).$$

This is exactly unnormalized linear attention. Storing the full list and evaluating this read gives the same result as storing the matrix. Negative similarities can give negative coefficients; it is not a probability mixture.

A two-dimensional example

Take keys $e_1=(1,0)^\top$, $e_2=(0,1)^\top$ and scalar values $2,3$. The memory is $S=(2,3)$ and querying either coordinate key retrieves its value exactly. If both keys are $e_1$, additive memory instead becomes $(5,0)$: neither target is retrieved correctly. A unit-step delta write makes the second value replace the first, leaving $(3,0)$. No deterministic read can distinguish identical keys with different targets.

Triadic linear attention: two keys for one value

Triadic linear attention adds a second key $r_t\in\mathbb R^E$ and query $s_t\in\mathbb R^E$. Its tensor state has shape $d_v\times d_k\times E$. Define joint features $z_t=k_t\otimes r_t$ and $u_t=q_t\otimes s_t$, where $(k\otimes r)_{(b-1)E+c}=k_b r_c$. Flattening the two key axes gives a matrix $M_t$ with $d_v$ rows and $d_kE$ columns:

$$M_t=M_{t-1}+v_tz_t^\top,\qquad M_tu_t=\sum_{j\le t}v_j(k_j^\top q_t)(r_j^\top s_t),\qquad M_0=0.$$

The read weights each value by two similarities multiplied together. In the collision example, keep both first keys equal to $e_1$ but choose second keys $f_1,f_2$, the two coordinate vectors in $\mathbb R^2$. Querying $(e_1,f_1)$ retrieves $2$ and querying $(e_1,f_2)$ retrieves $3$. The $d_kE$ joint coordinate keys $e_b\otimes f_c$ are orthonormal, so this construction can retrieve $d_kE$ arbitrary values exactly. Learned keys need not realize that construction.

The delta rule also acts on the joint key. With slice gates $0\le\alpha_{t,c}\le1$ and $D_t=I_{d_k}\otimes\operatorname{diag}(\alpha_{t,1},\ldots,\alpha_{t,E})$, decay before the delta write gives

$$M_t=M_{t-1}D_t(I-\beta_tz_tz_t^\top)+\beta_tv_tz_t^\top,\qquad y_t=M_tu_t.$$

The residual is $v_t-M_{t-1}D_tz_t$, and the order of decay and projection matters. For nonzero $z_t$, a step $\beta_t=1/\|z_t\|^2$ fits the new association exactly. Ordinary linear attention is recovered when $E=1$ and $r_t=s_t=1$. This connects the tensor construction directly to the same feature-memory and squared-error framework.

Transitions and effective keys

For the right-acting recurrence $S_t=S_{t-1}A_t+v_tk_t^\top$, define the chronological product $P_{j\to t}=A_{j+1}\cdots A_t$, with empty product $I$. Substitution gives

$$S_t=S_0P_{0\to t}+\sum_{j=1}^t v_jk_j^\top P_{j\to t}.$$

Thus $S_tq_t$ is a sum of values with coefficients $k_j^\top P_{j\to t}q_t$. This identity underlies recurrent/parallel descriptions; efficient algorithms require additional structure, as in structured state space duality. If coefficients depend on earlier states, the identity alone does not remove those dependencies.

For a delta write, $A_t=I-\beta_t k_tk_t^\top$. When $k_t\ne0$ and $\beta_t=1/\|k_t\|^2$, it projects onto $k_t^\perp$; when $\beta_t=2/\|k_t\|^2$, it is a Householder reflection. A projection is not a reflection, and learned step sizes need not give either special case.

The old effective key is $\widetilde k_j=P_{j\to t}^\top k_j$. Delta writes remove its component along the most recent unit key, but do not generally orthogonalize all old effective keys. For $k_1=e_1$, $k_2=(e_1+e_2)/\sqrt2$, $k_3=e_2$, unit-step writes give $\widetilde k_1=(1/2,0)^\top$ and $\widetilde k_2=(1/\sqrt2,0)^\top$: their inner product is nonzero.

When repeated delta writes converge

If the unit-key system $SK=V$ is consistent, cycling through all pairs with a fixed step $0<\beta<2$ and zero initialization converges to the minimum-norm solution $VK^+$, where $K^+$ is the Moore–Penrose pseudoinverse. This is the cyclic Kaczmarz connection. If the keys span the whole key space, the solution is unique. Otherwise an arbitrary initial state's action on the unobserved orthogonal complement is preserved.

The proof tracks the squared Frobenius error, which decreases at each write by $\beta(2-\beta)\|Ek\|^2$. A whole cycle strictly contracts nonzero error on the span of the keys. Consistency matters: scalar keys $1,1$, targets $0,1$, and step $1$ alternate between $0$ and $1$, although the least-squares solution is $1/2$.

Scalar decay and positional bias

For $A_s=\alpha_s I$, $0<\alpha_s\le1$, cumulative log decay is

$$d(j,t)=-\log\prod_{s=j+1}^t\alpha_s=\sum_{s=j+1}^t-\log\alpha_s.$$

It is additive along increasing positions. It can vanish between distinct positions, so it is not generally a metric. Multiplying an exponential attention weight by retention gives $e^{q_t^\top k_j/\tau-d(j,t)}$: decay is a negative logit bias.

For matrices, $-\log\|A_{j+1}\cdots A_t\|_2$ is generally only bounded below by the sum of local negative log norms. For example, $A=\operatorname{diag}(1,1/2)$ and $B=\operatorname{diag}(1/2,1)$ each have norm one, but $AB$ has norm $1/2$. Diagonal gates have coordinatewise log decay; a single scalar bias cannot generally reproduce them. Orthogonal transitions preserve norms but may change pairwise similarities when different keys receive different rotations.

A transition monoid contains the identity and is closed under multiplication. Individual rank-one projections or reflections do not form a closed family; their generated products do. Input dependence and norm preservation are separate properties.

Optimization, geometry, and constraints

A loss specifies the desired association; an algorithm specifies how to move toward it. Geometry measures movement, and constraints specify allowed states. These choices do not determine one another automatically.

Implicit updates differ from gradient steps

For differentiable strictly convex $h$ on a convex domain, define

$$D_h(X,Y)=h(X)-h(Y)-\langle\nabla h(Y),X-Y\rangle.$$

An implicit update minimizes $\ell(X)+D_h(X,X^-)/\eta$ over an admissible set, assuming a minimizer exists. Mirror descent instead minimizes the linearized loss $\langle\nabla\ell(X^-),X\rangle+D_h(X,X^-)/\eta$. With Euclidean $h$, the latter is a gradient step. The former, for squared-error memory, gives

$$S^+=S^-+\frac{\eta}{1+\eta\|k\|^2}(v-S^-k)k^\top.$$

For scalar $S^-=0$, $k=v=1$, $\eta=1$, the explicit result is $1$ and the implicit result is $1/2$. Calling both the same write would hide a real difference.

Forgetting differs from ridge regression

If the loss is zero, a Bregman update leaves the old state unchanged. Forgetting requires a penalty or a separate decay operation. Discounted additive writes store a discounted cross moment, whereas ridge regression fits all observed pairs:

$$S_\lambda=VK^\top(KK^\top+\lambda I)^{-1},\qquad\lambda>0.$$

Two scalar pairs with key and value $1$, and additive decay $1/2$, give memory $3/2$. Discounted ridge with the same observation weights gives $(3/2)/(3/2+\lambda)\le1$. The missing correlation inverse makes the operations different. Exact recursive least squares maintains that inverse as an additional state; the paper derives its update.

Normalization needs a domain and a constraint

  • Softmax. It maximizes $z^\top p-\tau\sum_i p_i\log p_i$ on the probability simplex $\{p\ge0:\sum_i p_i=1\}$. Equivalently, it normalizes positive weights $a_i=e^{z_i/\tau}$ by minimizing generalized relative entropy. It is not an idempotent projection of logits.
  • RMSNorm. Without learned gains or a numerical stabilizer, it sends nonzero $x\in\mathbb R^d$ to $\sqrt d\,x/\|x\|$, the nearest point on the radius-$\sqrt d$ sphere. Gains and a positive stabilizer change that exact interpretation.
  • Polar factor. For a full-column-rank $a\times b$ matrix $M$, $a\ge b$, its nearest matrix with orthonormal columns is $M(M^\top M)^{-1/2}$. Rank deficiency makes the completion nonunique; wide matrices use the transposed version. Muon approximately normalizes momentum in this way, not the weights.

A sphere is nonconvex. Its nearest-point map is neither globally unique nor nonexpansive: the unit-sphere images of $0.1e_1$ and $-0.1e_1$ have distance $2$, although the original distance is $0.2$. Compactness bounds states but does not establish convergence or stability. Frank–Wolfe is a separate convex constrained algorithm, using a linear minimizer and a convex-combination update; it is not an exact constrained Bregman projection.

A complete memory specification therefore includes the state, write objective, update algorithm, step sizes, transition, read, geometry, and constraint. A loss alone does not fix the read kernel or capacity.

Retrieval needs a criterion

For additive memory and query $q=k_*$, separate the target signal $s=\|k_*\|^2v_*$ from interference $n=\sum_{i\ne *}(k_i^\top k_*)v_i$. Define SNR as the ratio of expected squared norms.

If keys are independent $\mathcal N(0,I_d/d)$, values are independent $\mathcal N(0,I_{d_v})$, and keys and values are independent, then for $N\ge2$

$$\operatorname{SNR}_{\rm linear}=\frac{d+2}{N-1}.$$

Signal power is $d_v(1+2/d)$ and noise power is $d_v(N-1)/d$. For independent isotropic unit keys, the ratio is $d/(N-1)$. These explain an order-$d$ scale at a fixed expected-power threshold; they are not simultaneous high-probability guarantees for every stored item.

For softmax, condition on fixed keys and query, with the same independent zero-mean values. Writing $\Delta_i=q^\top k_*-q^\top k_i$ gives

$$\operatorname{SNR}_{\rm softmax}\mid K,q=\frac{w_*^2}{\sum_{i\ne *}w_i^2}=\frac1{\sum_{i\ne *}e^{-2\Delta_i/\tau}}.$$

The value dimension cancels. If every gap is at least $\delta$, this is at least $e^{2\delta/\tau}/(N-1)$. The formula depends on key norms, separation, and temperature. It does not assign a universal exponential capacity to transformers. As temperature tends to infinity, softmax becomes uniform averaging, not dot-product linear attention.

Retrieval energy is not a training loss

Modern Hopfield retrieval uses $E(q)=\tfrac12\|q\|^2-\tau\log\sum_i e^{k_i^\top q/\tau}$. Its stationary equation is $q=K\operatorname{softmax}(K^\top q/\tau)$. Arbitrary attached values define a separate read. Exponential pattern-storage results require specific geometric and probabilistic assumptions and a pattern list that grows with the number stored.

Cross-entropy instead has positive log-sum-exp: $\ell(z;c)=\log\sum_i e^{z_i}-z_c$. Its gradient is $\operatorname{softmax}(z)-e_c$. The shared calculus does not transfer Hopfield storage capacity to training weights or establish an exponential advantage over squared-error training.

Storage and features

Full attention stores $N(d_k+d_v)$ numbers. Linear memory stores $d_vd_k$ numbers. A finite feature kernel $\phi(q)^\top\phi(k)$ with feature dimension $D$ needs memory $\sum_i v_i\phi(k_i)^\top$ of size $d_vD$, and a further $D$ numbers for a normalization denominator. Random features approximate exponential kernels; their error and denominator control matter. Degree-$p$ homogeneous polynomial features have dimension $\binom{d_k+p-1}{p}$, not an automatic retrieval capacity equal to that dimension.

The triadic state uses $d_vd_kE$ numbers, an $E$-fold increase over the original state. The paper reports improved long-context modeling and recall with relatively few extra parameters, but storage and computation still increase. Factoring the product kernel saves work when forming interactions within a chunk; it does not eliminate the larger-state cost. Its state- and parameter-budget comparisons support specific architectural choices, rather than a capacity guarantee for arbitrary learned keys.

Hierarchical memories combine several states by the shape-correct read $o_t=\sum_r\lambda_t^{(r)}S_t^{(r)}q_t$. More levels affect storage and computation; their number alone does not determine an optimal hardware chunk size.

Propagation through depth

A residual update $x^+=x+f(x)$ retains and adds, but $f$ need not be a negative gradient. For example, $f(x_1,x_2)=(-x_2,x_1)$ has a skew-symmetric Jacobian, whereas a smooth scalar energy has a symmetric Hessian. Consequently not every residual block is an optimization step.

The residual stream retains intermediate computation

For a traversal with initial representation $h^{(0)}$ and realized sublayer contributions $c_j=f_j(h^{(j-1)})$, additive residual writes give

$$h^{(\ell)}=h^{(0)}+\sum_{j=1}^{\ell}c_j,\qquad Bh^{(\ell)}=Bh^{(0)}+\sum_{j=1}^{\ell}Bc_j$$

for any compatible linear read $B$. Later sublayers read this working memory, often through normalization and learned maps. Nonlinear reads need not distribute over the sum. The stream stores a superposition rather than a separate record for every layer: writes $u,-u$ leave the same final state as two zero writes. Keeping layer histories or additional streams changes storage and addressing.

Hyper-connections mix several residual streams. Doubly stochastic matrices are contractions but can also be norm-preserving permutations. Orthogonal mixing preserves the linear transition component; it does not by itself control the nonlinear block's full Jacobian. Whether contraction helps depends on the task and block, not merely on the axis.

Residual matrix transformers change the state and its structured interfaces. An outer-product layer write has the same algebra as an outer-product token write. This does not make every residual network a linear sequence model.

Standard attention heads project the full residual input: $W_K^{(h)}$ has shape $d_h\times d$, not $d_h\times d_h$ on a disjoint slice. Grouped-query attention shares key/value heads; it does not impose disjoint input blocks or orthogonal raw keys.

Does residual memory support useful depth?

DepthBench distinguishes layer count from useful sequential computation. At roughly matched parameter budgets, its main 400M experiments favor deeper, narrower Full Attention Residuals and Hyper-Connections models over ordinary pre-normalized blocks; the Hyper-Connections trend is weaker at 1.6B. Its layer-skipping, layer-swapping, and representation diagnostics test whether later computations depend on earlier results.

The access mechanism matters. Depth attention selects among separately stored outputs. Multiple residual streams propagate and mix them. In our row-stream convention, $H_i=A_iH_{i-1}+b_ic_i^\top$ and $z_\ell=H_{\ell-1}^\top r_\ell$ give the realized coefficient

$$w_{i\to\ell}=r_\ell^\top A_{\ell-1}\cdots A_{i+1}b_i.$$

Here $H_i\in\mathbb R^{a\times d}$, $A_i\in\mathbb R^{a\times a}$, $b_i,r_\ell\in\mathbb R^a$, and $c_i,z_\ell\in\mathbb R^d$; empty products are $I_a$. This connects depth reads to the unrolled sequence read. Changing a write can also change later learned mixing, so the coefficient alone is not a counterfactual causal effect.

Contraction can preserve a stream mean while erasing distinctions. For $J=\mathbf1\mathbf1^\top/a$ and $0\le\rho<1$, $A=J+\rho(I-J)$ has $A^n=J+\rho^n(I-J)$. This illustrates the paper's mixing-product observations; it does not prove that all doubly stochastic products collapse, and new writes continue to enter. Its block-storage analysis also illustrates how stored outputs may receive little read weight under a particular boundary schedule.

Layer sensitivity alone does not establish useful computation: skipping can disrupt inputs, an absolute swap-loss difference also records improvement, and normalized changes require nonzero reference updates. These diagnostics should accompany held-out performance. Equal weight budgets also do not equalize sequence caches, depth histories, or runtime: at approximately fixed backbone size $P\propto Ld^2$, the quantity $Ld$ grows as $\sqrt{PL}$, affecting cache storage of order $TLd$ in the benchmark's attention setting.

Two ways to couple depth and sequence

Mixture-of-Recursions reuses blocks and routes tokens to different recursion depths. Its router controls computation; it is analogous to, rather than identical with, a sequence forget gate.

The Recurrent Transformer instead stores persistent keys and values computed from a layer's output, so later positions read representations already processed by that same layer. At the current position it uses temporary input-derived keys and values, avoiding a circular definition of the output. These architectures change different parts of the dependency structure.

Training and optimizer states

Outer products in backpropagation

For one dense application $a=Wz$ and scalar loss $\mathcal L$, set $\delta=\nabla_a\mathcal L$. Then $\nabla_W\mathcal L=\delta z^\top$. If $z$ came through an activation, the corresponding activation derivative belongs in $\delta$. Batches and shared applications sum outer products. Nonlinear hidden layers preserve this local identity, while parameter-dependent factors generally prevent a fixed affine recurrence for the whole network.

Schedules weight realized writes

For $W_n=\alpha_nW_{n-1}-\eta_nG_n$, substitution yields

$$W_N=\left(\prod_{s=1}^N\alpha_s\right)W_0-\sum_{n=1}^N\eta_n\left(\prod_{s=n+1}^N\alpha_s\right)G_n.$$

Positive scalar retention gives log decay just as on the sequence axis. This is an exact identity for realized gradients. Changing the schedule also changes the trajectory and gradients, so the formula is not a counterfactual linear influence calculation. Learning rates weight writes; that supports an analogy to positional weighting, not a general identity with positional encodings.

The forward pass retrieves weight memory

For a dense SGD update with realized gradient $G_n=\delta_nz_n^\top$, define $\gamma_{n,N}=\prod_{s=n+1}^N\alpha_s$ for $0\le n\le N$. Right-multiplying the accumulated writes by a later forward input $q$ gives

$$W_Nq=\gamma_{0,N}W_0q-\sum_{n=1}^N\eta_n\gamma_{n,N}\delta_n(z_n^\top q).$$

The historical activations act as keys, signed error corrections as values, and the current activation as query. Batch/shared gradients add a sum over applications. This identity describes the realized trajectory; it does not guarantee recoverability of training examples, and other optimizers require their actual update directions. In a nonlinear network the feature representation also changes during training.

For a small example, train a linear map from zero on $e_1,e_2$ with targets $2,3$ using unit-step squared-error updates. The weight matrix is $W=(2,3)$. Its frozen forward pass gives $We_1=2$, $We_2=3$, and $W(e_1+e_2)=5$. The last read computes a new combination, and a subsequent nonlinearity transforms it further.

Batch noise is a different SNR

Let independent per-example gradients have nonzero mean $G$ and finite covariance $\Sigma$, with positive trace. A batch average of size $B$ has noise covariance $\Sigma/B$, hence

$$\operatorname{SNR}_{\rm grad}=\frac{B\|G\|^2}{\operatorname{tr}\Sigma}.$$

The simple noise scale $\operatorname{tr}\Sigma/\|G\|^2$ is related to empirical critical batch sizes under further modeling. It is not a hard memory capacity or a universal optimal batch size. Sampling without replacement from a finite population changes the covariance by a finite-population factor.

Preconditioning transforms both signal and noise. With $\Sigma=\operatorname{diag}(100,1)$, whitening changes the noise scale from $101$ to $200$ when $G=e_1$, but to $2$ when $G=e_2$. It can worsen or improve this coordinate-dependent ratio; convergence needs a separate analysis.

Optimizer states have different roles

Adam stores moving averages of gradients and squared gradients. Bias correction removes zero-initialization bias; it does not itself provide warmup. For a constant gradient, the bias-corrected states are constant at every step. Adam is not exactly diagonal Shampoo: second moments of products do not generally factor into products of second moments.

Lion uses one mixing coefficient to form the signed update direction and another to update momentum. Basic matrix Shampoo uses $L^{-1/4}GR^{-1/4}$, where $L,R$ accumulate left and right gradient products. Muon approximately takes a polar factor of momentum. Fisher natural gradient, Hessian preconditioning, and gradient-noise whitening are distinct constructions, even when particular models relate them.

Limits and open questions

The useful common language is a precise list of operations: what is stored, how it is written and read, which transition acts, and which geometry and constraints are imposed. Exact identities justify translations; conditional bounds need their assumptions; design analogies suggest experiments.

  • Can an efficient approximation to recursive least squares improve retrieval under measured key correlations at a fixed state budget?
  • How do finite-feature errors and small normalization denominators affect retrieval?
  • Which assumptions on nonlinear depth blocks let transition-norm bounds control the full Jacobian?
  • When does a preconditioner improve optimization under a specified relationship between signal and noise?

These questions have explicit operations and criteria. They do not assume that loss shape determines a universal capacity hierarchy or that normalization alone ensures stability.
