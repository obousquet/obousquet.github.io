The 60-year coincidence

In 1960, Widrow and Hoff published what they called the delta rule [1]: an adaptive algorithm for learning linear filters. Given a target output $y$ and a current prediction $\hat{y} = W x$, update the weights by:

$$W \leftarrow W + \eta\,(y - Wx)\,x^\top$$

The name "delta rule" refers to the error $\delta = y - Wx$ that drives the update. This is the same as stochastic gradient descent on the squared loss $\frac{1}{2}\|y - Wx\|^2$, rediscovered many times under different names: LMS, Widrow–Hoff, perceptron learning rule.

In 2024, Yang et al. introduced DeltaNet [2], a new sequence modeling architecture. Its memory update rule, applied token by token, is:

$$S_t \leftarrow S_{t-1} + (v_t - S_{t-1} k_t)\, k_t^\top$$

Where $S_t$ is a key-value memory matrix, $k_t$ is the new key, and $v_t$ is the value to store. They named it the "delta rule" because of its error-corrective structure. Neither the 2024 paper nor any subsequent discussion noted the exact correspondence: this is Widrow–Hoff, applied to tokens instead of training examples, with keys playing the role of inputs and values playing the role of targets.

The same algorithm, rediscovered 64 years later. This is not an isolated coincidence. Once you see the structure, it appears everywhere.

This post is about that structure.

The state update primitive

The common pattern in Widrow–Hoff and DeltaNet can be abstracted to a single recurrence:

$$S_t = A_t \cdot S_{t-1} + B_t \cdot x_t$$

where $S_t$ is a state (vector or matrix), $A_t$ controls how much of the old state to retain (forgetting), $B_t$ is an input operator, and $x_t$ is new information arriving at step $t$.

This recurrence appears across many domains under different names:

These systems differ in what $A$, $B$, and $x$ are — not in the structure of the operation. The question is: why does this one recurrence appear in such different contexts?

Three axes of computation

The answer becomes clear once we notice that the index $t$ in the table above is not always the same thing. It indexes different axes of computation:

  • Sequence axis ($t$ = token): processing a sequence of tokens left-to-right. The state $S_t$ is the KV cache of a linear attention head, accumulating information about past tokens.
  • Depth axis ($\ell$ = layer): processing a representation through successive layers. The state $x^{(\ell)}$ is the residual stream, refined by each layer.
  • Data axis ($n$ = example): training on a dataset. The state $W$ is the weight matrix, updated by each gradient step.

Every one of the systems in the table is the same operation applied along one of these three axes. This gives a natural memory hierarchy:

Working memory (sequence axis): the attention KV cache. Holds information about the current context. Ephemeral — reset for each new sequence.
Processing memory (depth axis): the residual stream. Accumulates and integrates representations across layers. Ephemeral — exists only during a forward pass.
Long-term memory (data axis): the weight matrices. Stores associations learned across the entire training dataset. Persistent.

Feed-forward network (FFN) layers are themselves associative memories [3]: each weight matrix $W$ stores key-value associations as its rows, and a forward pass through the FFN is a retrieval operation. Training — updating $W$ via gradient descent — is precisely the state update applied along the data axis.

Recurrent vs. attention: the SSD duality

On the sequence axis, the same computation has two equivalent forms. The recurrent form processes tokens one at a time:

$$S_t = A_t \cdot S_{t-1} + v_t k_t^\top, \qquad y_t = S_t\, q_t$$

The attention form processes all tokens in parallel:

$$y_t = \sum_{j \leq t} \underbrace{A_{j\to t}}_{\text{decay}} \cdot (k_j^\top q_t)\, v_j$$

where $A_{j\to t} = \prod_{s=j+1}^{t} A_s$ is the cumulative decay from position $j$ to $t$. These are not approximations of each other — they compute exactly the same thing. Dao and Gu [4] formalized this as the State Space Duality (SSD): both views are different factorizations of the same semiseparable matrix.

This duality extends to all three axes:

AxisRecurrent viewAttention viewInterpolation
SequenceRNN / SSMSoftmax / linear attentionChunked attention
DepthLayer-by-layer forward passDepth-wise attentionStage-wise groups
DataOnline SGDBatch gradient / pseudoinverseMini-batch SGD

The "chunk" column — chunked attention, stage groups, mini-batch SGD — interpolates between the two extremes in every case. Mini-batch SGD is exactly chunked attention on the data axis.

Positional encoding = forget gate

One of the most striking consequences of this framework is a complete unification of positional encodings and recurrent forget gates, established by Afzal [5].

Consider the cumulative product of transition matrices on the sequence axis:

$$P_{j \to t} = \prod_{s=j+1}^{t} A_s$$

This measures how much the state at position $j$ contributes to position $t$. In the log domain, $d(j,t) = -\log \|P_{j \to t}\|$ defines an asymmetric distance metric between positions. This distance is precisely the positional bias in the equivalent attention-view computation.

The monoid (algebraic structure) of the transition matrices $\{A_t\}$ determines the geometry of this distance, and hence both the recurrent decay behavior and the equivalent positional encoding:

Transition monoidRecurrencePositional encoding
$\{I\}$ (trivial)Linear attentionNoPE
$\mathbb{R}_{>0}$ (scalars)RetNetALiBi
Diagonal matricesMamba2 / GLAFoX
$\mathrm{SO}(2)$ (rotations)Complex-valued gatesRoPE
Householder reflectionsDeltaNetPaTH
Householder $\times$ scalarGatedDeltaNetPaTH-FoX

Every positional encoding scheme corresponds to a specific choice of transition monoid, and vice versa. RoPE arises from rotational transitions; ALiBi arises from scalar decay. They are not independently designed — they are dual descriptions of the same underlying geometry.

This table extends directly to the data axis. The forget gate in SGD with weight decay is $(1 - \lambda\eta_n)I$ — a scalar contraction. Unrolling the recurrence:

$$W_N = \sum_{j=1}^{N} \underbrace{\eta_j \prod_{s=j+1}^{N}(1 - \lambda\eta_s)}_{\text{influence weight of step } j} \, g_j$$

The cumulative retention $\rho(j,N) = \prod_{s=j+1}^{N}(1 - \lambda\eta_s)$ is the data-axis analogue of the positional decay. In the log domain:

$$d(j, N) = -\log \rho(j,N) \approx \lambda \int_j^N \eta(s)\, ds$$

The learning rate schedule $\eta(s)$ determines the metric geometry of training time — it is the positional encoding of the data axis:

LR scheduleData-axis geometrySequence-axis analogue
Constant $\eta_0$Uniform exponential decayALiBi / RetNet
Linear warmupCompresses early stepsShort-range PE handling
Cosine annealingLinear + sinusoidal correctionSinusoidal PE
Adam's bias correctionSchedule-free warmupPosition-dependent rescaling

Concretely: with $\lambda = 0.1$ and $\eta_0 = 10^{-3}$, gradients have a half-life of about 7,000 steps — gradients from further back contribute half as much as recent ones. Curriculum learning, where example selection depends on model state, is the data-axis analogue of input-dependent gating (Mamba/FoX).

Cost functions as the deeper story

So far we've described what the state update looks like. But there's a deeper question: why does this update have this particular form?

The answer: in most cases, the state update is a gradient step on a natural cost function. The cost determines everything — the update rule, the kernel structure, and the memory capacity.

The same cost form, different axes

Consider the quadratic cost. On the data axis, it's the per-example squared loss:

$$\mathcal{L}(W) = \tfrac{1}{2}\|y - Wx\|^2 \implies W \leftarrow W - \eta \nabla_W \mathcal{L} = W + \eta(y - Wx)x^\top$$

This is Widrow–Hoff. On the sequence axis, the same quadratic cost applied to the memory $S$:

$$\mathcal{L}(S) = \tfrac{1}{2}\|v - Sk\|^2 \implies S \leftarrow S + (v - Sk)k^\top$$

This is DeltaNet's delta rule. The two algorithms are gradient descent on the same cost function, applied to different axes.

Linear attention corresponds to an even simpler cost — the alignment objective $-\text{tr}(V^\top S K)$ — whose gradient is $-VK^\top$, giving a Hebbian (additive) update that ignores the current state. DeltaNet is strictly more principled: it uses the error $v - Sk$, accounting for what the current state already predicts.

From quadratic to exponential: the capacity hierarchy

Softmax attention corresponds to the modern Hopfield energy [6]:

$$E(q) = -\log \sum_i \exp(k_i^\top q) + \tfrac{1}{2}\|q\|^2$$

A gradient step on this energy gives softmax-weighted retrieval — i.e., softmax attention. The cost form (log-sum-exp rather than quadratic) is what gives softmax attention its exponential memory capacity: $e^{O(d)}$ patterns versus $O(d)$ for linear attention.

The same cost hierarchy appears on the data axis:

Cost formSequence axisData axisCapacity
Linear (alignment)Linear attentionHebbian$O(1)$/step
Quadratic (MSE)DeltaNetWidrow–Hoff / SGD$O(d)$
Log-sum-expSoftmax attentionCross-entropy$e^{O(d)}$

This is striking: cross-entropy training is the data-axis analogue of softmax attention. Both arise from the log-sum-exp cost, and both should achieve "exponential capacity" — the ability to separate exponentially many patterns. This suggests that natural gradient descent on cross-entropy is, in a precise sense, the optimizer that achieves the data-axis analogue of softmax attention's exponential retrieval performance.

The chain from cost to capacity

The cost function determines a complete cascade:

$$\mathcal{L} \;\xrightarrow{\;\nabla\;}\; \text{update rule} \;\xrightarrow{\;\nabla^2\;}\; \text{local metric} \;\xrightarrow{\;\text{Mercer}\;}\; \text{kernel} \;\xrightarrow{\;\text{capacity}\;}\; \text{SNR}$$

The gradient gives the update rule. The Hessian gives the local metric (preconditioning by the Hessian inverse = natural gradient). The metric induces a kernel via Mercer's theorem. The kernel determines the memory capacity and the signal-to-noise ratio of retrieval. Choosing the cost determines all of these simultaneously.

Depth as inner loop

The three axes are not symmetric, and this asymmetry is important to understand.

The sequence and data axes are outer loops — they accumulate persistent state. The depth axis is always an inner loop, nested inside one of the outer axes:

ModeInner axisOuter axisPersistent state
InferenceDepth ($\ell$)Sequence ($t$)KV cache $S_t^{(\ell)}$
TrainingDepth ($\ell$)Data ($n$)Weights $W^{(\ell)}$

At inference, each token triggers a complete traversal of all layers. The residual stream $x^{(\ell)}$ exists only during this traversal and is then discarded. The persistent state (KV cache) lives on the sequence axis. At training time, each example similarly triggers a full forward-and-backward depth traversal, and the persistent state (weights) lives on the data axis.

This means depth "mixes" with each outer axis. The KV cache update at layer $\ell$ involves quantities produced by the depth computation:

$$S_t^{(\ell)} = S_{t-1}^{(\ell)} + \underbrace{v_t^{(\ell)}}_{\text{computed by layers } 1\ldots\ell}\;(k_t^{(\ell)})^\top$$

And the weight gradient is a depth-data product:

$$\Delta W^{(\ell)} = \sum_n \underbrace{\delta_n^{(\ell)}}_{\text{backprop through depth}}\;(x_n^{(\ell-1)})^\top$$

This explains several things that might otherwise seem puzzling:

  • Why the residual stream is ephemeral: it belongs to an inner loop, not an outer one. Only the outer axes carry persistent memory.
  • Why the depth-axis duality is different: on the outer axes, the recurrent-vs-attention duality is about how to compute the persistent state update. On the depth axis, the analogous choice (layer-by-layer vs. depth-wise attention) is about how to organize the inner computation.
  • Why backpropagation is special: it is not a data-axis operation alone — it is a depth×data operation that unrolls the inner loop backward to compute the outer-axis gradient.

The depth axis is the shared computational substrate through which both outer axes operate. A transformer block is an instance of this: the block computes depth-axis transformations (attention + FFN) that produce the quantities (keys, values, gradients) used by both the sequence and data axes.

New predictions from the unified view

Unification is most valuable when it yields predictions that weren't obvious from any single field. Here are several.

Learning rate schedules as positional encodings

As shown above, the learning rate schedule $\eta(s)$ is the positional encoding of the data axis. This gives a new design principle: the rich literature on positional encoding for transformers should directly inspire LR schedule design.

For example: RoPE uses rotational structure to give tokens a periodic positional representation that extrapolates well beyond training length. What would a "RoPE-inspired" LR schedule look like? It would use a schedule with periodic structure — and it might have good extrapolation properties for fine-tuning on tasks with different training lengths.

DeltaNet = Widrow–Hoff: a completed circle

The delta rule hierarchy is the same on both axes:

MethodSequence axisData axis
AdditiveLinear attentionHebbian learning
Error-correctiveDeltaNetWidrow–Hoff / SGD
NormalizedNormalized DeltaNetNLMS
Spectral—Muon optimizer
Full curvature—Natural gradient / Newton
Batch optimal—Pseudoinverse $VK^+$

The table is asymmetric: the data axis has richer methods (Muon, natural gradient) that have no current sequence-axis counterparts. This points to unexplored architectures: what would a "Muon-style" linear attention look like? It would apply spectral normalization to the memory update — which is precisely what Mak and Flanigan's Residual Matrix Transformer [7] begins to approach.

Critical batch size = memory capacity

The retrieval SNR in a linear associative memory with $N$ stored patterns of dimension $d$ is:

$$\mathrm{SNR}_{\text{ret}}^{\text{linear}} = \frac{d}{N}$$

The memory saturates (SNR = 1) at $N_{\max} \sim d$ patterns. On the data axis, the gradient SNR for a mini-batch of size $B$ is:

$$\mathrm{SNR}_{\text{grad}}(B) = \frac{B\,\|G\|^2}{\mathrm{tr}(\Sigma)}$$

where $G = \mathbb{E}[g_n]$ is the true gradient and $\Sigma = \mathrm{Cov}(g_n)$ is the per-example gradient covariance. The "capacity threshold" — where SNR = 1 — is the critical batch size of McCandlish et al. [8]:

$$B_{\text{crit}} = \frac{\mathrm{tr}(\Sigma)}{\|G\|^2}$$

The correspondence is exact. The head dimension $d$ plays the role of the batch size $B$; the number of stored patterns plays the role of conflicting gradient directions (the effective rank of $\Sigma$). The optimal batch size $B^* \sim B_{\text{crit}}$ corresponds to the optimal chunk size $C^* \sim d$ in chunked attention.

This gives a new interpretation of $B_{\text{crit}}$: it is the retrieval capacity of the data-axis associative memory. And it suggests that preconditioning by natural gradient (the data-axis analogue of softmax) could reduce $B_{\text{crit}}$ exponentially, just as softmax extends linear attention's capacity from $O(d)$ to $e^{O(d)}$.

Open questions

The unified view raises several questions that we don't yet know how to answer:

  • The rotation monoid on the data axis. The sequence-axis table has RoPE (rotation group → periodic structure). What optimizer corresponds to a rotational forget gate? Such an optimizer would have "periodic" behavior in some sense — perhaps related to cyclical learning rates?
  • Exponential capacity on the data axis. Softmax attention achieves $e^{O(d)}$ capacity. Natural gradient on cross-entropy should be the data-axis analogue. Can we compute $B_{\text{crit}}$ for cross-entropy vs. MSE on a simple model and verify the exponential gap?
  • Depth-axis positional encoding. Standard residual connections use $A = I$ (no decay across layers). Hyper-connections [9] use learned mixing matrices. What is the "depth-axis positional encoding" — the geometry induced by the transition operator across layers?
  • The normalization–manifold conjecture. Softmax projects onto the probability simplex (Bregman projection), RMSNorm onto the sphere (Euclidean projection), polar decomposition (Muon) onto the Stiefel manifold (Frobenius projection). We conjecture that every normalization in deep learning is a metric projection onto a compact manifold, with the manifold determined by the algebraic structure of the memory. Can this be made into a theorem?
  • An RLS-Net. DeltaNet approximates the pseudoinverse by making a single pass. The Recursive Least Squares (RLS) algorithm achieves the pseudoinverse exactly by also maintaining the inverse key-correlation matrix $P_t = (\sum_{j \leq t} k_j k_j^\top)^{-1}$ as recurrent state. An "RLS-Net" would achieve optimal single-pass learning at the cost of $O(d_k^2)$ additional state. Can this be implemented efficiently and does it outperform DeltaNet?

The unified view doesn't just explain existing systems — it maps out a design space. Many combinations of (axis, monoid, cost, normalization) have not been explored. The framework suggests that ideas proven effective on one axis — like the exponential capacity of softmax or the spectral normalization of Muon — should have natural counterparts on the other axes waiting to be discovered.
